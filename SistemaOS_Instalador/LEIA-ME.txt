SISTEMA PARA CONTROLE DE ORDEM DE SERVIÇO (SistemaOS)
----------------------------------------------------

Instruções para Instalação:
1. Dê dois cliques no arquivo "instalar.bat" para rodar o instalador.
2. O instalador copiará automaticamente os arquivos para "C:\SistemaOS", configurará os modelos de relatórios de clientes, serviços e OS, e criará um atalho "SistemaOS" na sua Área de Trabalho (Desktop).

Requisitos do Banco de Dados:
- O sistema requer um servidor PostgreSQL rodando em: localhost:5432
- Nome do Banco: dbinfox
- Usuário: postgres
- Senha padrão do sistema configurada: Mae191161

Para iniciar o sistema após a instalação, basta dar dois cliques no atalho "SistemaOS" na sua Área de Trabalho!
